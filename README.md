# Chatbot PDF Reader

A lightweight, offline Question Answering (QA) system that answers user queries directly from PDF content without using any LLM or AI model for generation.

## Overview

This project provides an efficient solution for extracting information and answering questions from PDF documents in a completely offline environment. It requires no external AI models or internet connection, making it fast, private, and resource-efficient.

## Features

- 📄 **PDF Processing**: Extract and process text from PDF documents
- 🚀 **Lightweight**: No dependency on large language models (LLMs)
- 🔒 **Offline**: Works completely offline without internet connectivity
- ⚡ **Fast**: Quick response times due to minimal processing overhead
- 🔐 **Private**: All data stays local, no cloud processing required
- 💬 **QA System**: Answer questions based on PDF content

## How It Works

This QA system operates by:
1. Extracting text content from PDF files
2. Processing and indexing the content
3. Matching user queries against the indexed content
4. Retrieving and presenting relevant answers without generating new text
